# Console Animations in C++

Creative animations built using C++ console output and Windows libraries.

## Animations

### 🌀 Spiral Animation
- Spiral pattern rendered in console

### 💨 Fan Animation  
- Rotating fan blades simulation

### 〰️ Sine Wave
- Mathematical sine wave visualized in console

### 🪨 Stone Throw
- Character standing on roof throwing a stone
- Projectile motion simulation

## How to Run
> **Note:** Uses Windows-specific libraries (`windows.h`, `conio.h`)
> Open in Dev C++ on Windows and press F11 to compile and run.

## Skills Used
C++ · Mathematics · Logic Building · Console Graphics
